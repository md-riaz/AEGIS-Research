<!-- SLIDE 16: Safety Analysis -->
<div class="slide" id="s16">
<h2>Safety Analysis: Why 0% Unsafe?</h2>
<div class="two-col">
<div>
<h3>Structural Safety Guarantee</h3>
<p style="margin-bottom:16px">SafeDash achieves 0% unsafe SQL by design, not by chance:</p>
<ul>
<li><strong>No SQL generation by LLM</strong> &mdash; model produces JSON intent only</li>
<li><strong>Template-only compilation</strong> &mdash; SQL from allow-listed patterns</li>
<li><strong>Closed vocabulary</strong> &mdash; all identifiers from semantic layer</li>
<li><strong>AST validation</strong> &mdash; rejects forbidden constructs</li>
<li><strong>No string interpolation</strong> &mdash; SQL injection structurally impossible</li>
</ul>
<p style="margin-top:16px;font-weight:600;color:var(--accent)">Proposition 1: No query in Q_safe(L,r) can reference a table, column, or row not enumerated in L for role r.</p>
</div>
<div>
<h3>Baseline Unsafe Queries (7/99)</h3>
<div class="card" style="border-left:3px solid var(--red)">
<ul style="font-size:.88em">
<li>INSERT/UPDATE/DELETE statements</li>
<li>UNION clauses exposing other tables</li>
<li>Subqueries against system tables</li>
<li>Unbounded JOINs (no LIMIT)</li>
<li>References to unauthorized columns</li>
</ul>
</div>
<div class="card" style="margin-top:12px;text-align:center;background:rgba(16,185,129,.08)">
<p style="font-weight:600;color:var(--green);font-size:1.1em">SafeDash: 0 unsafe queries<br>out of 99 generated</p>
</div>
</div>
